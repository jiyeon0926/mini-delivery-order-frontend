# 🍴 EAT NOW | Bootstrap & jQuery 기반 UI
EAT NOW는 고객이 장바구니에 메뉴를 담아 주문을 하고, 사장님이 가게·메뉴·주문·리뷰를 관리할 수 있는 미니 배달 주문 서비스입니다. <br>
Bootstrap과 jQuery를 기반으로 UI를 구현했으며, AJAX를 활용해 Spring Boot 기반 REST API 서버와 연동했습니다. <br><br>
